# v0.7.0：效率优先编排

v0.7.0 的目标不是增加更多 Agent，而是在不降低验收质量的前提下减少不必要的模型、上下文、审查、探测、日志与仓库 I/O。

## 主要变化

- 短任务和高度耦合的单范围长任务保持 Direct；中等顺序任务使用一个 Lite Executor。
- Lite 首次选择 normal 成本档位，不再因文本复杂度直接使用 Sol/xhigh。
- `--compact` 仅输出状态、档位、预算、真实模型、审批和下一步。
- 模型健康结果可跨进程复用；只探测当前主候选，fallback 在真实需要时懒探测。
- Git 审计只读取 dirty/untracked/deleted 内容；RunStore 追加事件不再反复解析全部 JSONL。
- 单轮 criterion evidence 错误不再污染后续修订。

## 证据边界

三档基准测量路由结果、模型档位、控制面字节数和确定性路由耗时。控制面字节数可作为上下文/token 压力的代理，但不是服务端计费 token。真实模型 token、一次完成率与端到端墙钟收益仍需在同一模型、同一仓库快照和相同验收条件下完成 connected A/B。
